# 开发指南

## 运行环境

- Node.js：建议 20+（前端 Vite 对 Node 版本有要求）
- ffmpeg（可选，用于视频缩略图和元数据提取）：
  - macOS: `brew install ffmpeg`
  - Windows: `winget install --id Gyan.FFmpeg`（或从 [ffmpeg.org](https://ffmpeg.org/download.html) 下载）
  - Linux: `sudo apt install ffmpeg`（或使用对应发行版的包管理器）

## 本地启动

1. 安装依赖

```bash
cd server && npm install
cd ../client && npm install
```

1. 一键启动（推荐）

```bash
cd .
yarn dev
```

说明：
- 会启动 `server` + `client`，并**尝试启动** `ai-service`（若 `:8002` 已有 ai-service 在跑，会自动跳过，避免 “address already in use”）。

1. 手动启动服务端

```bash
cd server
npm run dev
```

1. 启动前端

```bash
cd client
npm run dev
```

## 文件监听策略

默认 `TIDY_WATCHER_MODE=auto`。本地固定磁盘会启用实时 watcher；UNC、映射网络盘（例如 `Z:\` 指向 NAS/SMB）、可移动盘或不可访问目录会自动降级为 fallback discover，避免 chokidar 在 Windows 网络盘上报 `UNKNOWN` 或 `The system cannot open the file`。

可选环境变量：

- `TIDY_WATCHER_MODE=auto|off|on`
- `TIDY_DISABLE_WATCHER=1`：兼容旧开关，等价于 `TIDY_WATCHER_MODE=off`
- `TIDY_WATCHER_FALLBACK_INTERVAL_MS=3600000`：fallback discover 间隔，默认 60 分钟，最小 60 秒

使用 `Z:\_document\photos` 这类网络盘时，建议保持默认 `auto`，不要强制开启 watcher。系统会在健康状态里显示“降级扫描”，并定期补扫缺失文件。

## 人脸（可选功能）

### InsightFace（可选增强）

如果你希望更接近 Immich/PhotoPrism 的人像体验（更强检测/embedding/可做 GPU 加速），可以使用独立的 Python AI 服务：`ai-service/`（承载人脸 + CLIP/智能搜索推理能力）。

- 说明与启动方式见：`ai-service/README.md`
